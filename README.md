# Супер Сережа 16-BIT: Битва в Библиотеке (SuperSergo)

Ретро-аркадный воксельный 3D-платформер для Android в стиле 16-bit эпохи SNES / Mega Drive с процедурным WebGL-движком и встроенным чиптюн-синтезатором.

![Super Seryozha](app/src/main/res/mipmap-xxxhdpi/ic_launcher.png)

## 🎮 Об игре

Вы играете за системного администратора Серёжу, которому поручено навести порядок в огромной государственной библиотеке:
чинить зависшие ЭЛТ-компьютеры с BSOD, подключать матричные принтеры, прыгать по парящим книжным полкам и каталожным шкафам, избегать летающих книг и уворачиваться от строгих смотрительниц читального зала!

### Особенности игры:
- **Кастомный 3D-воксельный движок на WebGL:** полусферическое освещение (hemisphere lighting), динамический точечный свет от фонарика сисадмина, контактные мягкие тени и неоновое свечение терминалов.
- **9 разнообразных биомов/миров:**
  1. *WORLD 1-1* — Книгохранилище
  2. *WORLD 1-2* — Каталожный Зал
  3. *WORLD 1-3* — Читальный Зал
  4. *WORLD 1-4* — Главный Архив
  5. *WORLD 1-5* — Бункер ЭВМ
  6. *WORLD 1-6* — Обсерватория
  7. *WORLD 1-7* — Ледяное хранилище
  8. *WORLD 1-8* — Цифровой океан
  9. *WORLD 1-9* — Ядро библиотеки
- **Кинематографичный 45-секундный синематик-пролог** с динамической сменой 9 планов камеры и сюжетными субтитрами.
- **Интерактивные ретро-терминалы ЭВМ («Электроника МС-6105»):** мини-игры по соединению разъёмов, кабелей и устранению системных сбоев.
- **Адаптивный сенсорный стик:** плавающий виртуальный джойстик на левой половине экрана + удобный кластер кнопок действий под большой палец правой руки.
- **Комиксные облачка диалогов:** забавный профессиональный сисадминский юмор и диалоги со смотрительницами.
- **Встроенный WebAudio чиптюн-синтезатор:** аутентичный 8/16-битный саундтрек без внешних тяжелых MP3-файлов (размер APK всего ~100 КБ!).

## 🕹 Управление

### На смартфонах (Сенсор):
- **Левая половина экрана:** Касание в любой точке вызывает динамический аналоговый стик для перемещения влево/вправо.
- **[A] (Зеленая/Розовая кнопка):** Прыжок.
- **[B] (Голубая кнопка):** Починка техники (ПК, принтер, терминал).
- **[X] (Фиолетовая кнопка):** Очки сисадмина (+5 к компиляции, замедление времени / подсветка целей).
- **[Y] (Оранжевая кнопка):** Бросок системной дискеты 3.5".

### На ПК (Клавиатура):
- **A / D** или **Стрелки влево / вправо:** Перемещение.
- **Пробел / W / Стрелка вверх:** Прыжок.
- **E:** Починить технику.
- **Q:** Очки сисадмина.
- **F:** Бросить дискету.
- **M:** Вкл/выкл звук и музыку.

## 🛠 Сборка проекта

### Требования:
- JDK 17 (Java Development Kit)
- Android SDK (API Level 34, Build-Tools 34.0.0+)

### Быстрая сборка через скрипт `build.sh`:
```bash
# Сборка Debug APK
./build.sh debug

# Сборка Release APK
./build.sh release

# Сборка Release Android App Bundle (AAB) для Google Play / RuStore
./build.sh bundle

# Сборка всех таргетов одновременно
./build.sh all
```

Все собранные артефакты будут находиться в каталоге `app/build/outputs/`.

## 📱 Системные требования

- **ОС:** Android 8.0 (Oreo, API 26) или новее.
- **Архитектура:** Любая (ARMv7, ARM64, x86, x86_64).
- **Экран:** Поддержка альбомной ориентации (16:9, 18:9, 19.5:9, 20:9, 21:9) с учётом вырезов и чёлок камер (`safe-area-inset`).
